# SPU Professional Portfolio — React

Portfolio starter built from the Vibe Coding assignment brief. It follows the brief's information architecture: Hero → About → Skills → Projects → Experience/Process → CV + Contact, and emphasizes project evidence, responsive design, public deployment, GitHub/source, and explaining the Vibe Coding process.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Customize
Edit `src/main.jsx`:
- `profile` — your name, headline, email, GitHub, LinkedIn
- `projects` — replace placeholders with real projects, role, tech, evidence, and outcomes
- `skills` — keep only skills you can explain/prove

Put your real CV at `public/resume.pdf` so the CV button works.

## Deploy
Recommended: Vercel, Netlify, GitHub Pages, or Cloudflare Pages. After deployment, test the public URL in incognito and at desktop/tablet/mobile widths as required by the assignment.
